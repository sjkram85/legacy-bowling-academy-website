# Legacy Bowling Academy

Public website for Legacy Bowling Academy, a DBA of Legacy Computing Services, LLC. Admin and billing live in the Legacy Computing Services employee portal (https://legacycomputingservices.com/portal/).

Booking and payment URLs stay blank until they are pasted into `index.html`. The payment link is a Legacy Computing Services, LLC URL. The academy does not have its own merchant account. See [docs/editing.md](docs/editing.md).
